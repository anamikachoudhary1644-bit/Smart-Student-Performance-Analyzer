# Smart Student Performance Analyzer

## 1. Problem Statement

Checking student performance manually can take time because marks, attendance, and assignment details have to be checked separately. It can also be difficult to quickly find the grade, performance category, or subject that needs more focus.

This project provides a simple Python program that takes student details, marks, attendance, and assignment information and gives a basic performance report.

## 2. Scope of the Project

The project is made for basic student performance analysis. It can be used to:

- Take student name and roll number.
- Take Maths, Python, and English marks.
- Calculate total marks and percentage.
- Assign a grade based on percentage.
- Check attendance and completed assignments.
- Find the subject with the lowest marks.
- Give a simple recommendation for improvement.
- Show the final performance report.

The current project works through the command line and does not store student information permanently.

## 3. Target Users

The main users of this project are:

- Students
- Teachers
- People learning basic Python programming
- Users who want to check basic student performance

## 4. High-Level Features

- Student details input
- Marks and percentage calculation
- Grade calculation
- Performance category
- Subject-wise recommendation
- Attendance warning
- Assignment suggestion
- Final student performance report
